# UnblockingAPI

**Unblock any URL.** We build the API and tools that get developers and AI agents past bot walls, CAPTCHAs and JS-heavy pages — clean HTML back, no proxy dashboards or browser farms to manage.

🌐 [unblockingapi.com](https://unblockingapi.com) · 📖 [API docs](https://unblockingapi.com/docs) · ✉️ [hello@unblockingapi.com](mailto:hello@unblockingapi.com)

## What we build

| | |
|---|---|
| **[`mcp`](https://github.com/unblockingapi/mcp)** | Official MCP server — gives Claude, Cursor and other AI agents the ability to fetch bot-protected pages and run structured searches through UnblockingAPI. `npm i -g @unblockingapi/mcp` |
| **[`unblocked-app`](https://github.com/unblockingapi/unblocked-app)** | Free desktop app — a local browser-rendering API and MCP server that runs on your own machine and IP. [Download](https://unblockingapi.com/tools) |
